# 餃作 GYOZA — 訂單串接 Google Sheet 設定步驟

網站結帳 →（POST）→ Google Apps Script 網頁應用程式 → 寫入 Google Sheet ＋ 寄確認信

```
顧客按「送出訂單」
   │  JSON：姓名、手機、Email、取餐方式、地址、品項 id 與數量（不含價格）
   ▼
Apps Script doPost
   ├─ 驗證欄位、以「商品」工作表的價格重新計算金額
   ├─ 產生訂單編號 GZ20261116-001（每日流水號）
   ├─ 寫入「訂單」「訂單明細」
   ├─ 寄確認信給顧客、寄新訂單通知給店家
   └─ 回傳 { ok, orderNo, total }
店家在「訂單」把狀態改成 可取餐／已出貨／已取消 → 自動寄信通知顧客
```

## 一、建立試算表與程式（約 5 分鐘）

1. 到 Google 雲端硬碟新增一個 **Google 試算表**，命名例如「餃作訂單」。
2. 在試算表上方選單點 **擴充功能 → Apps Script**。
3. 把編輯器裡預設的 `Code.gs` 內容全部刪掉，貼上本資料夾 [`Code.gs`](Code.gs) 的全部內容，按 💾 儲存。
4. 上方函式下拉選單選 **`setup`**，按 **▶ 執行**。
   - 第一次會跳出授權視窗：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。
     （這是你自己寫的程式，Google 對未經審核的個人程式都會顯示這個警告。）
   - 執行完成後回到試算表，會看到「訂單」「訂單明細」「商品」三個工作表。

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 左邊齒輪「選取類型」選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
4. 按 **部署**，複製「網頁應用程式」網址（`https://script.google.com/macros/s/……/exec`）。
5. 把這個網址交給 Claude，或自己貼到 `index.html` 的
   `const ORDER_API_URL = '';` 引號裡。

> 之後如果修改了 `Code.gs`：**部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**。
> 這樣網址不會變，網站不用改。若用「新增部署作業」會產生新網址。

## 三、日常使用

| 工作表 | 用途 |
|---|---|
| **訂單** | 一筆訂單一列。「狀態」欄有下拉選單，改成 **可取餐／已出貨／已取消** 會自動寄信給顧客，並在「備註」記錄寄信時間。 |
| **訂單明細** | 一個品項一列，方便用樞紐分析統計銷量。 |
| **商品** | 價目表。網站下單時以這裡的 **單價** 計價；取消勾選「上架」即停售（顧客下單會被擋下）。 |

- **改價格**：同時改「商品」工作表與網站 `index.html` 的 `products`，兩邊要一致（網站顯示的價格來自 `index.html`，實際收費以試算表為準）。
- **新增商品**：在「商品」加一列（商品ID 要與網站 `products` 的 `id` 相同）。
- **店家通知信箱**：預設是部署者的 Gmail。要改的話：Apps Script →「專案設定」→「指令碼屬性」→ 編輯 `OWNER_EMAIL`。

## 四、注意事項

- Gmail 個人帳號每天約可寄 **100 封** Apps Script 郵件（每筆訂單會寄 2 封：顧客＋店家）。訂單量大時可改用 Google Workspace 帳號（每天 1,500 封）。
- 目前**沒有線上付款**，付款於取餐或到貨時處理。
- 防護：伺服器端驗證格式、價格以試算表為準、同時下單用鎖避免編號重複、使用者輸入不會被試算表當成公式執行、隱藏欄位擋簡單機器人。
